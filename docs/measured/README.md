# Raw measured logs

The seven `.log` files under `logs/` plus `logs/summary.md` are the **raw output of
real GitHub Actions runs**. They are produced by `scripts/run_all.sh`, uploaded as an
artefact, and committed here as well so they can be read offline (artefacts expire,
the repository does not).

## Contents

| File | Description |
| --- | --- |
| `logs/summary.md` | Summary table generated by `run_all.sh` (case, exit code, first verdict line) |
| `logs/01_*.log` to `logs/07_*.log` | Full stderr of each case, including call stacks, shadow memory map and stack frame layout |

The prose analysis of each verdict is in [`../03-measured-results.md`](../03-measured-results.md);
how to read the report fields is described in [`../02-report-anatomy.md`](../02-report-anatomy.md).

## How to regenerate

```bash
make && bash scripts/run_all.sh   # needs Linux / WSL / Docker (local output goes to reports/, already gitignored)
```

Alternatively, on the GitHub repository page go to Actions -> `asan-reproduction` ->
**Run workflow**, and download the `asan-reports` artefact at the bottom of that run.
